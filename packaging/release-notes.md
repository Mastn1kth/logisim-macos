# Logisim 5.0.0 packages

Ready-to-use builds for digital-logic classes and lab work. Java is bundled in
every package and does not need to be installed separately.

## Choose your download

- **Apple Silicon Mac (M1–M5):** `Logisim-5.0.0-macOS-Apple-Silicon.zip`
- **Intel Mac:** `Logisim-5.0.0-macOS-Intel.zip`
- **Typical Intel/AMD Windows PC:** `logisim-evolution-5.0.0-amd64.msi`
- **Portable Intel/AMD Windows:** `logisim-evolution-5.0.0-windows-amd64.zip`
- **Windows on ARM:** use one of the `aarch64` files

The macOS application is displayed as **Logisim**. It is ad-hoc signed, verified,
repacked, extracted, and launched on matching Intel and Apple Silicon GitHub
runners before publication. It is not notarized with a paid Apple certificate,
so the first launch may require Control-click → **Open**.

Windows packages are the unchanged official Logisim-evolution 5.0.0 binaries.
Their sizes and SHA-256 digests are verified against the upstream release.
`SHA256SUMS.txt` contains checksums for every downloadable file.

## По-русски

Это готовые сборки для лабораторных работ. Java уже находится внутри. Для Mac
с M1/M2/M3/M4/M5 скачивай файл `Apple-Silicon.zip`, для обычного Windows —
`amd64.msi`. Русский язык встроен и выбирается в настройках Logisim.

These packages are based on the official
[Logisim-evolution 5.0.0](https://github.com/logisim-evolution/logisim-evolution/releases/tag/v5.0.0)
release. This repository provides independent packaging and does not claim the
upstream simulator as its own work.
